# Mono design — Hero Section

Тестовое задание (Middle+ Web Designer): главный экран для архитектурной студии Mono design.
Концепция «Plan → Place»: путь от инженерного чертежа к готовому интерьеру.

## Запуск

Открыть `index.html` в Chrome (нужен интернет: шрифты Google Fonts, GSAP, Lenis с CDN).

| URL-параметр | Что делает |
|---|---|
| `?mode=static` | статичный финальный кадр без анимаций — для импорта в Figma (html.to.design) |
| `?theme=light` / `?theme=dark` | тема |

Клавиши: `T` — сменить тему, `R` — повторить входную анимацию.

Мастер-кадр: 1920 × 1080 по модульной сетке клиента (1rem = 10px при 1920, другие ширины масштабируются пропорционально).

## Сдача

> Папка `static/` в репозиторий не входит, она собирается локально: `node tools/build-static.mjs`.

- `static/` — 18 ключевых кадров 1920×1080 для Figma (9 кадров × 2 темы), CSS встроен, JS нет. `k04-hero` — основной статичный экран
- `static/{dark|light}-final-static.html` — **Final static**: чистый главный экран (без скрытых служебных слоёв), для показа и макета
- `static/{dark|light}-final-static-expanded.html` — **Final static expanded**: доска со всеми элементами: hero, раскрытое окно с подписью, следующий блок (кадры 1920×1080 с подписями)
- `FIGMA-ANIMATION.md` — как собрать из кадров прототип со Smart Animate: порядок, триггеры, длительности, кривые
- `ui-kit.html` — UI kit для Figma: палитра, семантические переменные (dark / light), типографика, сетка, отступы, движение, компоненты со всеми состояниями
- `tokens/tokens.json` — дизайн-токены (W3C DTCG) для импорта в Figma Variables
- `REPORT.md` — отчёт по пунктам ТЗ: какие решения приняты и почему

## Токены → код

```
tokens/tokens.json ──node tools/build-tokens.mjs──▶ css/tokens.css   (CSS-переменные + классы .t-*)
                   ──node tools/build-kit.mjs────▶ ui-kit.html
css + index.html ──node tools/build-static.mjs──▶ static/*.html      (CSS встроен, без JS)
```

Цвета/размеры меняются только в `tokens/tokens.json`, затем три команды выше.

## Структура

- `index.html` — разметка hero и следующего блока
- `css/tokens.css` — переменные из токенов (генерируется)
- `css/style.css` — компоненты и раскладка, только на переменных
- `css/ui-kit.css` — оформление страницы UI kit
- `js/main.js` — входная анимация, параллакс по курсору, скролл-переход (GSAP + ScrollTrigger + Lenis)

## Сетка для Figma (кадр 1920 × 1080) — по гайдлайнам клиента

| Layout grid | Параметры |
|---|---|
| Columns | Count 7 · Type Stretch · Margin 60 · Gutter 8 (колонка ≈ 250,3) |
| Rows | Count 6 · Type Stretch · Margin 60 · Gutter 8 (ряд ≈ 153,3) |

Раскладка по сетке:

| Зона | Координаты |
|---|---|
| Шапка | верхнее поле, Y 0–60 |
| Асайд (тег, интро, подзаголовок, CTA) | X 0–577 = поле + колонки 1–2 |
| Контентная зона (окно из колонн) | X 577–1920 = колонки 3–7 + поле (1343) |
| Подписи чертежа, интро | ряд 1, Y 60–213 |
| Окно | ряды 2–6, Y 221–1020; 5 колонн = 5 колонок, зазор = гаттер 8 |
| Низ H1 | конец ряда 4, Y 697; вторая строка начинается от границы асайда X 577 |
| Подзаголовок / карточка | начало ряда 5, Y 705 |
| Полоса этапов | нижнее поле, Y 1020–1080 |

Значения сняты со страницы «Паттерн» гайдлайнов клиента (асайд 577 + 1343). Если в исходном Figma-файле поля/гаттер отличаются — меняется только `tokens/tokens.json`.
